# Online Food Delivery Customer Analysis (SQL)

## 📌 Project Overview
This project performs an exploratory data analysis (EDA) on an e-commerce food delivery dataset using *SQL Server (SSMS)*. The goal is to uncover key consumer insights, analyze user demographics (age, occupation, and marital status), and identify target customer segments to optimize food delivery marketing campaigns.

## 🛠️ Technical Skills Demonstrated
* *Data Cleaning & Schema Management:* Resolved real-world CSV import errors including string truncation constraints (varchar(MAX)) and data type validation failures (Allow Nulls).
* *Data Aggregation:* Leveraged group-by matrices (GROUP BY, COUNT, AVG) to summarize transactional volumes.
* *Conditional Filtering:* Applied multi-clause conditional queries (WHERE, AND) to isolate high-value consumer demographics.

## 📊 Key Queries & Business Questions Explored
1. *Total Volume Tracking:* Counted total historical transactions to scale market size.
2. *Age Demographic Audits:* Checked minimum, maximum, and average customer age spreads.
3. *Gender Ordering Habits:* Grouped total consumer orders by gender segments.
4. *Occupational Clustering:* Discovered which careers (Students vs. Salaried vs. Independent) generate the highest order frequency.
5. *Hyper-Targeted Filtering:* Isolated student cohorts under specific age thresholds to analyze young consumer trends.

## 💡 Key Business Insights Discovered
* The primary consumer base for this platform leans heavily toward younger demographics, specifically students under the age of 25.
* Target marketing campaigns yield maximum ROI when focused on localized student clusters rather than older professionals.
